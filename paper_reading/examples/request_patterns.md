# 使用示例

## 单篇快速判断

```text
快读：https://arxiv.org/abs/2210.03629
```

期望：

- 一页判断；
- 核心贡献；
- 最强证据；
- 最大限制；
- 是否值得深读。

## 单篇标准深读

```text
深读：https://arxiv.org/abs/2210.03629
```

期望：

- 默认深读包；
- 关键结论有页码/章节/图表定位；
- 对 Agent 的环境、动作、规划、工具和评测做专项检查；
- 给出可迁移点和最小验证实验。

## 机器人论文

```text
深读并重点检查真机实验：https://arxiv.org/abs/2303.03378
```

期望：

- 本体、传感器、动作空间和控制频率；
- 数据来源、训练预算和推理频率；
- 仿真与真机设置；
- 泛化、失败恢复、安全与部署成本；
- 公平比较与可复现性。

## 多篇综述

```text
综述以下五篇，比较 memory、planning 和评测协议：
<链接1>
<链接2>
<链接3>
<链接4>
<链接5>
```

期望：

- 比较矩阵；
- 共识和分歧；
- 方法演化；
- 研究空白；
- 推荐阅读顺序。

## 输出 PPT

```text
基于已有深读包，产出 12 页组会 PPT，突出方法和失败案例：
paper_id：yao-2022-react
```

期望：

- 从 `deck_storyboard.md` 生成；
- 一页一个论点；
- 图表与结论相邻；
- 引用原始图号/页码；
- 渲染后逐页检查。
